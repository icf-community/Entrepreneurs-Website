# each direct dependency by exact pinned version (there's no [project]
# dependency list to install from any more — see README.md), then
# `pip freeze`. Never freeze your own dev venv into this file — it will
# also pick up whatever unrelated tooling (linters, security scanners, an
# editable self-install) happens to be sitting in that venv.

# declares pymupdf-layout and pymupdf4llm, which pull onnxruntime, numpy,
# networkx, protobuf and more into this image: an ML runtime inside the PDF
# parser's trust boundary and a much larger image, for features this service
# does not use (it only reads text and span geometry). Revisit if 1.x stops
# getting fixes; do not take 2.x through a blind "update everything".
